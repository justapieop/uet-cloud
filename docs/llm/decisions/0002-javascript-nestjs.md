# D-0002: JavaScript and NestJS application stack

- **Status:** Accepted
- **Date:** 2026-09-24

## Context

The project needs a confirmed application technology stack to guide implementation and Azure integration choices.

## Decision

- Build the application using JavaScript with NestJS.

## Consequences

- Implementation and Azure SDK choices should support the JavaScript/Node.js ecosystem and NestJS.
- This decision does not establish additional Azure services, deployment workflows, or application architecture details beyond the existing Clean Architecture direction.
